An empty table passes every other test. That’s why this one goes first.

-- 0 rows or an old load: I stop
SELECT table_name, total_rows,
       storage_last_modified_time
FROM `region-us`.INFORMATION_SCHEMA.TABLE_STORAGE
WHERE table_schema = 'raw';

What I look forOne row per sale line. If a sale shows up twice, everything inflates.

Two coffees on one receipt aren’t a duplicate: the line tells them apart.

-- 0 rows = it passes
SELECT sale_id, line_no, COUNT(*) AS n
FROM stg_sales
GROUP BY sale_id, line_no
HAVING COUNT(*) > 1
    OR sale_id IS NULL OR line_no IS NULL;

In dbtunique + not_null

What I look forNo empty or future dates, discounts between 0 and 100, and profit = revenue − cost.

checkrulerows
sale_datenot empty1
sale_datenot in the future0
discount_pct0–1002
profitrevenue − cost0

Ranges are set per column: a 150% markup can be normal.

-- All 0 = it passes
SELECT COUNTIF(sale_date IS NULL) AS no_date,
  COUNTIF(sale_date > CURRENT_DATE()) AS future,
  COUNTIF(discount_pct NOT BETWEEN 0 AND 100) AS bad_discount,
  COUNTIF(ABS(revenue - cost - profit) > 1) AS bad_profit
FROM stg_sales;

In dbtnot_null + accepted_values

What I look forThat every sale points to a store that exists. If not, it’s an orphan row and the total by store won’t add up.

store_idrowsamount
S-14121,240,000

12 sales with no store: the total by area comes up short.

-- 0 rows = it passes
SELECT f.store_id, COUNT(*) AS rows_affected,
       SUM(f.amount) AS amount_affected
FROM stg_sales f
LEFT JOIN stg_stores d USING (store_id)
WHERE d.store_id IS NULL
GROUP BY f.store_id;

00When to review

Before deciding,not after.

  1. 1
    A new source arrivesBefore anyone builds on it.
  2. 2
    Two areas bring different figuresBefore the meeting turns into an argument.
  3. 3
    An AI assistant gets connectedBefore it answers with the wrong number.
✓It’s worth it if
  • Two areas bring different figures.
  • Someone is about to decide with that number.
  • Copilot or Claude will read that data.
✗It isn’t for this
  • What’s needed is a financial audit.
  • Someone wants a signature that everything is perfect.
  • Nobody will decide anything with the result.
